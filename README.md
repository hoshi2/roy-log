# ロイログ（roy-log）

XAU/USD のトレード配信（ロイさんのシグナル）を貼り付けて記録し、実際の値動きと
照合するための個人用ツール。単一HTMLファイル・ビルド不要。

旧リポジトリ名は `pattern-radar`。2026-09-20 に `roy-log` へ改名しました。

公開URL: https://hoshi2.github.io/roy-log/

## 画面

- **貼る** — 配信テキストを貼るとゾーン・条件ライン・MA条件・利確目標を自動で抜き出す。LINEのトーク履歴（.txt）の一括取り込みにも対応
- **タイムライン** — 保存した配信を日付順に表示し、実際の値動きと照合して判定。発動率・TP到達率のサマリーつき
- **チャート** — ローソク足にゾーンと利確目標を重ねて表示
- **設定** — TwelveData APIキー、Firebaseクラウド保存、JSONバックアップ

## データの扱い

- ブラウザの `localStorage` が正。オフラインでも動く
- Firebaseを設定すると `roylog` コレクションに保存され、端末間で同期する（習慣アプリ・お金アプリと同じ仕組み）

詳しい構造は `CLAUDE.md` に書いてあります。
